# Torrent
Build by Sia Gupta
Torrent is a concept for defense hardware that reconstructs a soldier's 
surroundings in 3D, in real time, from their own perspective. It's built 
to give infantry spatial awareness in close-quarters combat, where GPS 
and traditional navigation often fail.

## What this repo does
This repo contains the computer vision component: training a YOLOv8 
model from first-person solider footage, as a step toward real-time 3D reconstruction.

## Status
This is an early-stage / solo startup project. Next steps: apply for a government SBIR contract.
